# Next: окружение и граница сервера с клиентом

- **`NEXT_PUBLIC_*` уезжает в бандл браузера.** Это не переменная окружения, а публичная
  константа, вшитая в сборку. Ключ, токен и строка подключения с таким префиксом считаются
  утёкшими. Секрет читается только в серверном коде.
- **Значения `NEXT_PUBLIC_*` подставляются на сборке, а не на старте.** Смена значения без
  пересборки ничего не меняет; в образе Docker это значит build-arg, а не переменную
  контейнера.
- **`"use client"` ставится на границе, а не на всём поддереве.** Директива делает
  клиентским весь импортируемый оттуда граф. Если компонент стал клиентским ради одного
  обработчика, вынеси этот кусок в отдельный маленький компонент.
- **`next/font` ходит в сеть на этапе сборки.** Без доступа наружу сборка не падает, а
  висит. Проверяя сборку в изолированном окружении, держи это первой гипотезой.
- **Серверное окружение в клиентский компонент не протекает.** `process.env` там пуст для
  всего, кроме публичного префикса, и читается как `undefined` вместо ошибки.
