# Гайд студента: AI-проверка PR

AI-проверка — твой инструмент для быстрого фидбэка перед тем, как
наставник посмотрит код руками. AI читает твой PR и пишет комменты прямо
в GitHub.

## Как запустить

1. Залей решение задачи в свой fork репозитория задания.
2. Открой PR в upstream (или в свой fork — зависит от инструкций автора).
3. На странице задачи в платформе нажми **«Сдать задание»**, вставь URL твоего PR.
4. После submission кнопка **«Запустить AI»** станет активной.
5. Через ~30-90 сек обнови вкладку с PR — там появится новый review.

## Что означают verdict'ы

AI всегда отдаёт один из четырёх verdict'ов:

| Verdict | Смысл |
|---|---|
| **LOOKS_GOOD** ✅ | По формальным признакам всё ок. Это **не** значит «наставник примет» — финальное слово за человеком. |
| **MINOR_ISSUES** ⚠️ | Есть мелкие замечания: naming, форматирование, мелкие баги в edge cases. Можешь исправить и пушнуть, либо оставить как есть. |
| **MAJOR_ISSUES** 🔴 | Серьёзные проблемы: логические ошибки, нарушения архитектуры, отсутствие тестов на критичную ветку. Исправь перед тем как звать на ручное ревью. |
| **OFF_TOPIC** ❓ | AI не понял, что в PR'е соответствует задаче. Часто — потому что diff не в той папке, либо PR пустой. Проверь, что коммитнул то, что надо. |

## Когда retry полезен

Если получаешь **FAILED iteration** (красный значок) — посмотри на сообщение:

- `review.diff.too_large` — diff > 1500 строк. Разбей PR на несколько меньших,
  открой второй PR на следующий кусок.
- `review.pr.draft_not_supported` — PR в Draft. Нажми **«Ready for review»**
  на GitHub и запусти AI снова.
- `review.no_installation` — GitHub App не подключён к твоему репозиторию.
  Подключи через `/settings/integrations` или попроси автора курса.
- `review.github.unavailable` / `review.llm.unavailable` — временная
  проблема внешнего сервиса. Retry через 30 сек.
- `review.rate_limit.exceeded` — превышен дневной лимит (100 итераций/день
  или 20/submission). Подожди до следующего дня.

## Idempotency

Повторный запуск AI **на тот же commit_sha** возвращает результат
предыдущей COMPLETED-итерации без повторного вызова LLM. Это значит:

- Можешь нажать «Запустить AI» сколько угодно раз без коста — пока коммит тот же.
- Push'нул новый коммит → запуск создаст новую итерацию.
- Force-push на тот же sha → результат предыдущей итерации (sha не изменился).

## Что AI **не** видит

- Контекст других задач курса.
- Твоё прохождение материалов.
- Содержимое референс-репозиториев автора.
- Историю твоих предыдущих сдач.

AI видит только: diff PR + общие правила автора (PROJECT guidelines) +
инструкции для этой задачи (ISSUE spec).

## Если AI ошибся

Иногда AI пишет ерунду — он не идеален. Если уверен, что замечание не по
делу:

1. Игнорируй конкретный комментарий — он не блокирует merge.
2. Опиши кратко в комментарии PR, почему не согласен (для наставника-человека).
3. Запроси ручное ревью через **«Отправить на проверку»** в платформе.

Наставник всегда выше AI — финальное решение за человеком.
