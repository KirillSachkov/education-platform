# Public-source asset boundary

The root MIT license covers the owner's code, developer documentation, original
demonstration data and the neutral geometric illustrations in this source tree.
The generator is `frontend/scripts/generate-public-assets.mjs`; the book mark and
anonymous avatar are original illustrations, not product branding or a photograph.
The neutral replacements retain the existing icon, Open Graph and avatar URLs.

The owner's original product logos, icons, Open Graph artwork, author portrait and
legal Markdown/PDF files are excluded from this public source tree. Their original
files remain in the coordinator's private archive and are not relicensed by MIT.
Deleting or replacing them here does not remove them from the original private Git
history. Publication must use the separate clean initial snapshot.

Legal documents are supplied separately at runtime. The public application contains
no substitute terms, and preserves document versions and public URLs. See
[the private runtime configuration](docs/public-source.md#private-runtime-assets).
Third-party fonts retain [their separate license](THIRD_PARTY_LICENSES/README.md).
